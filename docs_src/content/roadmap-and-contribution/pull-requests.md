# Pull Requests

The abbr:DDO framework is envisioned as a standard framework for solving a wide range of use-cases and for implementing, testing and comparing novel coordination methods. Contributions from the community that extend its use-cases, enhance its methodological features, or improve its usability are highly appreciated. We kindly ask that any modifications or changes to the source code be shared by submitting them as pull requests to the GitHub repository's [Pull Requests](repo:pulls) tab.

Please label your pull request as either <span class="gh-label gh-label-bug">bug</span>, <span class="gh-label gh-label-duplicate">duplicate</span>, or <span class="gh-label gh-label-question">question</span>, whichever applies best.
