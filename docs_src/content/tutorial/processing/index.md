# Processing

This section covers how to analyze and visualize optimization results with the abbr:DDO framework. Having previously defined and executed a distributed design optimization problem according to [Tutorial > Problem Definition and Algorithm Execution](../problem-definition-and-algorithm-execution/index.md), this guide illustrates how to process the data generated during the optimization execution (further detail on [Data Logging](../../framework-architecture/data-logging.md)) for the [SSBJ](../../examples/SSBJ/index.md) Example.

Immediate information is provided to the user through the terminal during execution. This is further detailed in [Terminal Output](terminal-output.md).
A dedicated abbr:GUI of the abbr:DDO framework enables comprehensive (post-) processing of entire optimization executions. This is further detailed in [DDO Viewer](ddo-viewer.md).
