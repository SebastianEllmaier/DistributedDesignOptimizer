1. Problem formulation and sources

This folder implements the Supersonic Business Jet (SSBJ) problem following the formulation provided in the DMDO framework by Bayoumy:

- https://github.com/Ahmed-Bayoumy/DMDO/tree/DEV/tests/SBJ

The computation of the physical responses is based on the analytical models introduced by Bayoumy.
(For a detailed overview, see the associated draw.io diagram.)

Equivalent implementations of the same SSBJ formulation can also be found in MATLAB:

- https://github.com/khbalhandawi/NoHiMDO/tree/master
- https://github.com/bastientalgorn/NoHiMDO/tree/master/SBJ

These implementations are largely consistent with Bayoumy’s formulation.


2. Relation to other SSBJ formulations

In addition to the Bayoumi / Khbalhandawi / Talgorn formulation, alternative versions of the SSBJ problem exist in the literature:

- De Wit (2009)
  - Objective differs fundamentally: Maximizes range instead of minimizing total weight subject to a range constraint
  - Uses the same physical response models as Bayoumi, Khbalhandawi, and Talgorn
  - Different coupling strcutre between subsystems
  - MATLAB implementation available in the literature

- WhatsOpt and GEMSEO implementations
  - Simplified versions of the De Wit formulation: Reduced number of design variables, simplified disciplinary models and couplings
  - Introduction of global variables, which is not compatible with the distributed character and decentralized formulation of our DDO framework.
  - Relevant sources:
    - https://gemseo.readthedocs.io/en/stable/examples/formulations/plot_sobieski_idf_example.html
    - https://github.com/whatsopt/SSBJ-OpenMDAO/tree/master/ssbj_disciplines


3. Reference solutions

Since this implementation follows the formulation of Bayoumi, Khbalhandawi, and Talgorn, their reported reference solutions are considered.

3.1 Bayoumi

- Objective / result
  - Minimum total weight: ≈ 34,300 lb

- Dual Update Hyperparameters
  - beta = 1.8
  - gamma = 0.9

- Solver
  - Not explicitly specified (MDO formulation)

- Iteration scheme
  - Parallel

- Consistency tolerances
  - Inner loop: 1e-12
  - Outer loop: 1e-10


3.2 Khbalhandawi

- Objective / result
  - Best found optimum: ≈ 33,600 lb
  - Reported realistic solution: ≈ 30,000 lb

- Dual Update Hyperparameters
  - beta = 1.3
  - gamma = 0.5
  - Initial weight penalty: w0 = 1

- Solver
  - MADS (Mesh Adaptive Direct Search)

- Iteration scheme
  - Sequential

- Consistency tolerances
  - Inner loop: 1e-12
  - Outer loop: 1e-12


3.3 Talgorn

- Objective / result
  - Best found optimum: ≈ 33,600 lb
  - Reported realistic solution: ≈ 30,000 lb

- Dual Update Hyperparameters
  - beta = 1.3
  - gamma = 0.5

- Solver
  - MADS 

- Iteration scheme
  - Not explicitly specified (typically sequential in NHATC)

- Iteration limits
  - Inner iterations: NI = 20
  - Outer iterations: NO = 200

- Consistency tolerances
  - Inner loop: 1e-9
  - Outer loop: 1e-9
